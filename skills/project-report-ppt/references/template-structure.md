# 项目汇报 PPT 模板结构

基于最新调整后的 `tmp/20260127.pptx` 提取并固化。这份模板是“已完成项目汇报模板”，适合复用其版式、章节节奏、标题层级和信息组织方式，不适合直接沿用其中的业务正文。

## 结构概览

- 总页数：61 页
- 目录页：第 2、12、16、56、59 页
- 封面页：第 1 页
- 结束页：第 61 页
- 主要大章节：
  - 一、项目基本情况
  - 二、国内外研究进展
  - 三、完成情况及主要创新成果
  - 四、总结和展望
  - 五、专家意见回应

## 页面节奏

- 第 3-11 页：项目背景、概况、负责人、组织管理、关键节点、变更事项、经费执行
- 第 13-15 页：国内外研究进展与研究基础
- 第 17-49 页：整体研究内容、课题技术路线、研究内容分解、试点验证
- 第 50-55 页：指标完成情况、论文专利软著、创新点总结
- 第 57-60 页：总结展望与专家意见回应

## 模板特点

- 封面、目录、章节切换页和结束页具有强模板属性，应尽量沿用原模板文本和视觉层级
- 正文页多为“章节标题 + 页内副标题 + 研究内容横条 + 浅色正文底板 + 下方图示/表格”结构
- 课题页、创新点页、指标页在版式上高度重复，适合用作自动填充骨架
- 目录页、章节标题、大量副标题有固定语义，不宜自行改写

## 固化原则

- `assets/template-project-report.pptx` 已更新为这份新模板，后续生成默认以此为视觉基线
- 回归校验中的模板对照页，也统一切换到 `tmp/20260127.pptx`
- 固定模板栏位沿用原模板：
  - 目录页
  - 章节大标题
  - 结束页
  - 非动态页的固定副标题
- 项目专属内容只从输入材料提取或扩写，不得沿用模板业务正文

## 使用建议

- 把模板当作“视觉框架 + 叙事节奏”，不要当作正文语料来源
- 当输入材料不足时，优先依据课题目标、研究内容和考核指标扩写，而不是借用模板旧项目内容
- 当页面正文较长时，优先适配背景框和正文框，确保文字始终落在背景框内
